# Scripts do ambiente

Não há scripts executáveis de provisionamento nesta fundação. Eles serão acrescentados junto dos componentes que executam, com comandos e resultados verificados.

Responsabilidades previstas:

- Localizar ou obter as revisões exatas dos serviços.
- Preparar o ambiente integrado de desenvolvimento com configuração explícita.
- Validar pré-requisitos do cluster e carregar as imagens corretas.
- Executar a jornada integrada e registrar a combinação de versões.
- Limpar somente recursos próprios, com dados preservados quando o cenário exigir recuperação.

Não criar scripts que retornem sucesso sem realizar essas operações. O [guia de desenvolvimento](../docs/development.md) e o [guia de release](../docs/release.md) definem as convenções aplicáveis.
